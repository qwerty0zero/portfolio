# DESIGN.md — Дизайн-система и правила верстки

Этот документ является строгим дизайн-контрактом проекта. Любой код верстки, компонентов и секций обязан следовать правилам, токенам и ограничениям, описанным ниже.

---

## 1. Фундаментальные принципы (Core Principles)

1. **Desktop-First**:
   - Базовая верстка, сетки и композиции проектируются для десктопных экранов от `1200px` до `1920px`.
   - Адаптация под планшеты и смартфоны выполняется каскадно через нисходящие медиа-запросы `@media (max-width: 1024px)`, `@media (max-width: 768px)`, `@media (max-width: 480px)`.
2. **Zero Third-Party Component Libraries**:
   - Запрещено использовать сторонние UI-библиотеки компонентов (Tailwind UI, Shadcn, Material UI, Bootstrap и др.).
   - Все UI-элементы (кнопки, карточки, бейджи, модалки, списки) создаются с нуля на нативном HTML5, CSS и Astro-компонентах.
3. **Прямые углы (Sharp Corners)**:
   - Кнопки, карточки, блоки, инпуты и большинство элементов интерфейса имеют **строго прямые углы** (`border-radius: 0`).
   - Исключение: только круглые аватарки/индикаторы (`border-radius: 50%` / `--radius-full`), когда это прямо запрошено.
4. **Запрет на тени и декоративные эффекты**:
   - **Запрещено** использовать `box-shadow`, `text-shadow`, `filter: blur()`, `backdrop-filter` и градиентные свечения без явного запроса пользователя.
   - Визуальная иерархия и разделение слоев строятся исключительно на **контрасте фонов** и **четких границах** (`--border`, `--border-dim`).
5. **DRY и утилитные классы вместо дублирования в компонентах**:
   - Общие стили типографики (семейство шрифта, базовые начертания, высота строки, цвет, трекинг) вынесены в `global.css`.
   - В компонентах запрещено хардкодить `font-family`, `font-size: clamp(...)` или цвета текста — используются готовые глобальные утилитные классы (`.heading-*`, `.text-body*`, `.text-mono*`).

## 3. Типографика, токены и утилитные классы

Используются локальные оптимизированные шрифты в формате `.woff2` из `/fonts/` с полной поддержкой кириллицы (RU, UK), латиницы (EN) и расширенной латиницы (PL).

### Семейства шрифтов
- **Заголовки (`--font-heading`)**: `'Dela Gothic One', sans-serif`
- **Основной текст (`--font-body`)**: `'Fira Sans Extra Condensed', sans-serif`
- **Моноширинный (`--font-mono`)**: `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace`

### Начертания (Font Weights)
- `--font-weight-regular`: `400`
- `--font-weight-medium`: `500`
- `--font-weight-bold`: `700`

> [!IMPORTANT]
> Все фиксированные размеры шрифтов в px-эквивалентах обязаны быть **строго четными числами** (`10px`, `12px`, `14px`, `16px`, `18px`, `20px`, `24px`). Нечетные размеры (`11px`, `13px`, `15px`, `17px`) запрещены.

| :--- | :--- | :--- | :--- |

| `--font-size-xs` | `0.75rem` | `12px` | Бейджи, теги технологий, метаданные дат/категорий |
| `--font-size-sm` | `0.875rem` | `14px` | Вторичный текст, компактные списки, кнопки SM, инпуты |

### Высота строки (Line Heights)
- `--line-height-display`: `1.1` (для сверхкрупных заголовков `display` и `h1`)

### Межбуквенный интервал (Letter Spacing)
- `--letter-spacing-tighter`: `-0.02em` (крупный display)
- `--letter-spacing-tight`: `-0.01em` (заголовки h1-h4)
- `--letter-spacing-mono`: `0.04em` (технический моноширинный код, кнопки, инпуты)
- `--letter-spacing-wide`: `0.08em` (подзаголовки секций, теги направлений)
- `--letter-spacing-wider`: `0.1em` (eyebrow-метки над секциями)

### 📖 Руководство: Как использовать классы типографики в компонентах

Вся типографика в компонентах верстается через семантические глобальные классы. **Запрещено** хардкодить `font-family`, `font-size` или `line-height` локально в блоке `<style>` компонента.

#### 1. Заголовки
Все заголовки автоматически получают `'Dela Gothic One'`, uppercase, `--line-height-heading` и цвет `--text`. Различается только размер:
```html
<h1 class="heading-display">АРХИТЕКТУРА И КОД</h1> <!-- Экран Hero -->
<h1 class="heading-1">КАТАЛОГ ПРОЕКТОВ</h1>          <!-- Страницы каталогов -->
<h2 class="heading-2">НАПРАВЛЕНИЯ</h2>              <!-- Заголовки секций -->
<h3 class="heading-3">FRONTEND CORE</h3>            <!-- Заголовки карточек -->
<h4 class="heading-4">КАК МЫ РАБОТАЕМ?</h4>          <!-- Вопросы FAQ, вкладки -->
```

#### 2. Моноширинный текст, метки и бейджи
Все классы моноширины получают `--font-mono` и `--letter-spacing-mono`:
- `.text-eyebrow`: верхняя надпись над заголовком секции (`accent`, `bold`, uppercase, трекинг `0.1em`).
- `.text-mono-label`: технический заголовок блока параметров (`muted`, uppercase, трекинг `0.08em`).
- `.text-mono-sm` (алиас `.mono-sm`): 14px моноширинный текст (номера карточек, метаданные).
- `.text-mono-xs` (алиас `.mono-xs`): 12px моноширинный текст (чипы технологий, теги).
- `.text-mono-2xs` (алиас `.mono-2xs`): 10px моноширинный микро-текст.
- `.text-code`: блок исходного кода (14px, `line-height: 1.6`).

Пример:
```html
<span class="text-eyebrow">// Стек и компетенции</span>
<span class="text-mono-label">Core Domains:</span>
<span class="text-mono-xs">TypeScript</span>
<span class="text-mono-sm">01 / 07</span>
```

#### 3. Основной текст и параграфы
Все классы получают `'Fira Sans Extra Condensed'` и правильный контраст:
- `.text-lead`: вводный параграф секции (адаптивный крупный размер, `--text-dim`).
- `.text-lead-accent`: акцентная строка под именем в Hero (`accent`, `bold`, uppercase).
- `.text-body-lg`: расширенный параграф биографии, ответов FAQ или описания проекта.
- `.text-body`: стандартный абзац текста (16px).
- `.text-body-sm`: компактный текст списков обязанностей и подписей (14px).
- `.text-body-bold`: полужирный акцент внутри текста (`bold`, `--text`).

Пример:
```html
<p class="text-lead">Проектирование высоконагруженных веб-интерфейсов с нулевым runtime overhead.</p>
<p class="text-body-lg">Разрабатываю современные лендинги и веб-приложения на Astro и TypeScript...</p>
<li class="text-body-sm">Проектирование дизайн-систем и токенов интерфейса.</li>
```

#### 4. Цветовые утилиты текста
Для точечного переопределения цвета без дублирования правил:
- `.text-accent`: цвет `--accent`
- `.text-primary`: цвет `--text` (100% контраст)
- `.text-dim`: цвет `--text-dim` (вторичный текст, 75%)
- `.text-muted`: цвет `--text-muted` (приглушенный, 50%)
- `.text-inverse`: цвет `--text-inverse` (на инверсных фонах)

## 5. Анимации, переходы и интерактивность

Дизайн-система фиксирует набор кривых плавности (easing curves) и длительностей (durations), гарантирующих плавный 60/120fps отклик интерфейса.

### Токены анимаций и переходов
- **Кривые плавности (Easing)**:
  - `--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);` — стандартная кривая для hover-эффектов и переключения цветов.
  - `--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);` — кинетическая кривая быстрого входа и мягкой остановки (шторки, слайды, появление).
  - `--ease-in-expo: cubic-bezier(0.7, 0, 0.84, 0);` — кривая ускорения при закрытии и исчезновении.
  - `--ease-spring: cubic-bezier(0.2, 0, 0, 1);` — упругая пружинная кривая для интерактивных плашек.
- **Длительности (Durations)**:
  - `--duration-fast: 150ms;` — микродвижения, hover на ссылках, переключение иконок.
  - `--duration-normal: 250ms;` — карточки, стрелки, раскрытие аккордеона.
  - `--duration-smooth: 300ms;` — прогресс-бары, появление плашек.
  - `--duration-slow: 450ms;` — движение шторки меню, переходы между полноэкранными состояниями.

### Готовые составные токены переходов (Shortcuts)
- `--transition-fast: var(--duration-fast) var(--ease-standard);`
- `--transition-base: var(--duration-normal) var(--ease-standard);`
- `--transition-smooth: var(--duration-smooth) var(--ease-out-expo);`
- `--transition-curtain-open: var(--duration-slow) var(--ease-out-expo);`
- `--transition-curtain-close: var(--duration-slow) var(--ease-in-expo);`
- `--transition-theme: background-color 200ms ease, color 200ms ease, border-color 200ms ease;`

### 📖 Руководство: Как использовать токены анимаций в компонентах

```css
/* Простые hover-состояния: нативный быстрый переход */
.button-interactive {
  transition:
    background-color var(--transition-fast),
    border-color var(--transition-fast),
    color var(--transition-fast);
}

/* Сдвиг декоративных стрелок и маркеров */
.link-anchor:hover .arrow-icon {
  transform: translate(2px, -2px);
  transition: transform var(--transition-fast);
}

/* Шторки, выпадающие панели и крупные оверлеи */
.modal-curtain-enter {
  transition: transform var(--transition-curtain-open);
}
.modal-curtain-exit {
  transition: transform var(--transition-curtain-close);
}
```

### Правила анимаций
1. **Разрешенные свойства анимаций**:
   - Анимируются **только** свойства композитинга: `opacity` и `transform` (`translate`, `scale`, `rotate`).
   - **Строго запрещено** анимировать свойства пересчета макета (`width`, `height`, `margin`, `padding`, `top`, `left`, `bottom`, `right`, `filter: blur`).
2. **Использование `will-change`**:
   - Применяется точечно к анимируемым элементам перед началом движения:
     ```css
     .animated-element {
       will-change: transform, opacity;
     }
     ```
   - В JS/Web Animations API сбрасывается в `auto` после завершения анимации во избежание утечек памяти на мобильных GPU.
3. **Доступность (Reduced Motion)**:
   - Любая анимация обязана мгновенно отключаться при системном флаге `prefers-reduced-motion: reduce`:
     ```css
     @media (prefers-reduced-motion: reduce) {
       *, *::before, *::after {
         animation-duration: 0.01ms !important;
         animation-iteration-count: 1 !important;
         transition-duration: 0.01ms !important;
         scroll-behavior: auto !important;
       }
     }
     ```

## 6. Адаптивность и мобильные стандарты

1. **Touch Targets**:
   - На экранах `<= 768px` все интерактивные элементы (`<button>`, `<a>`, `<input>`) должны иметь область клика/тапа не менее **44x44px**.
2. **Отключение Hover на тач-устройствах**:
   - Сложные hover-состояния активируются только на десктопах с мышью через `@media (hover: hover) and (pointer: fine)`.
   - На сенсорных устройствах контент должен быть виден сразу либо раскрываться по тапу.
3. **Контроль переполнения**:
   - `overflow-x: hidden` / `overflow-x: clip` на уровне страницы. Запрещены элементы, создающие горизонтальный скролл.
