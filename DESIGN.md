# DESIGN.md — Дизайн-система и правила верстки

Этот документ является строгим дизайн-контрактом проекта. Любой код верстки, компонентов и секций обязан следовать правилам, токенам и ограничениям, описанным ниже.

---

## 1. Фундаментальные принципы (Core Principles)

1. **Desktop-First**:
   - Базовая верстка, сетки и композиции проектируются для десктопных экранов от `1200px` до `1920px`.
   - Адаптация под планшеты и смартфоны выполняется каскадно через нисходящие медиа-запросы `@media (max-width: 1024px)`, `@media (max-width: 768px)`, `@media (max-width: 480px)`.
2. **Zero Third-Party Component Libraries**:
   - Запрещено использовать сторонние UI-библиотеки компонентов (Tailwind UI, Shadcn, Material UI, Bootstrap и др.).
   - Все UI-элементы (кнопки, карточки, бейджи, модалки, списки) создаются с нуля на нативном HTML5, CSS и Astro-компонентах.
3. **Прямые углы (Sharp Corners)**:
   - Кнопки, карточки, блоки, инпуты и большинство элементов интерфейса имеют **строго прямые углы** (`border-radius: 0`).
   - Исключение: только круглые аватарки/индикаторы (`border-radius: 50%` / `--radius-full`), когда это прямо запрошено.
4. **Запрет на тени и декоративные эффекты**:
   - **Запрещено** использовать `box-shadow`, `text-shadow`, `filter: blur()`, `backdrop-filter` и градиентные свечения без явного запроса пользователя.
   - Визуальная иерархия и разделение слоев строятся исключительно на **контрасте фонов** и **четких границах** (`--border`, `--border-dim`).

## 3. Типографика и шрифты

Используются локальные оптимизированные шрифты в формате `.woff2` из `/fonts/`:

- **Заголовки (`h1`–`h6`, логотипы, крупные цифры)**:
  - Семейство: `'Array', sans-serif` (`--font-heading`)
  - Начертание: 400 (Regular)
  - `line-height`: `1.1` – `1.2`
  - `letter-spacing`: `-0.01em`
- **Основной текст (`body`, `p`, `span`, ссылки, списки)**:
  - Семейство: `'Khand', sans-serif` (`--font-body`)
  - Начертания: 400 (Regular), 700 (Bold)
  - `line-height`: `1.4` – `1.5`
- **Моноширинный текст (код, технические метки)**:
  - Семейство: `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace` (`--font-mono`)

## 5. Анимации и интерактивность (GSAP, CSS, will-change)

1. **Разрешенные свойства анимаций**:
   - Анимируются **только** свойства композитинга: `opacity` и `transform` (`translate`, `scale`, `rotate`).
   - **Строго запрещено** анимировать свойства пересчета макета (`width`, `height`, `margin`, `padding`, `top`, `left`, `bottom`, `right`, `filter: blur`).
2. **Использование `will-change`**:
   - Применяется точечно к анимируемым элементам перед началом движения:
     ```css
     .animated-element {
       will-change: transform, opacity;
     }
     ```
   - В JS/GSAP сбрасывается обратно в `auto` после завершения анимации во избежание утечек памяти на мобильных GPU:
     ```javascript
     gsap.to(el, {
       opacity: 1,
       y: 0,
       duration: 0.6,
       clearProps: "willChange",
     });
     ```
3. **Использование GSAP**:
   - GSAP применяется для сложных сценариев: таймлайны (timeline), stagger-появление списков, scroll-анимации (ScrollTrigger).
   - Для простых состояний наведения (`:hover`, `:focus`) используется нативный CSS `transition: transform 200ms ease, opacity 200ms ease`.
4. **Доступность (Reduced Motion)**:
   - Любая анимация (CSS или GSAP) обязана отключаться при системном флаге `prefers-reduced-motion: reduce`:
     ```javascript
     const prefersReducedMotion = window.matchMedia(
       "(prefers-reduced-motion: reduce)",
     ).matches;
     if (prefersReducedMotion) {
       // мгновенное отображение без анимаций
     }
     ```

## 6. Адаптивность и мобильные стандарты

1. **Touch Targets**:
   - На экранах `<= 768px` все интерактивные элементы (`<button>`, `<a>`, `<input>`) должны иметь область клика/тапа не менее **44x44px**.
2. **Отключение Hover на тач-устройствах**:
   - Сложные hover-состояния активируются только на десктопах с мышью через `@media (hover: hover) and (pointer: fine)`.
   - На сенсорных устройствах контент должен быть виден сразу либо раскрываться по тапу.
3. **Контроль переполнения**:
   - `overflow-x: hidden` на уровне страницы. Запрещены элементы, создающие горизонтальный скролл.
