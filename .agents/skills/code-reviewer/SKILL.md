## 📋 Чеклист аудита качества кода

### 1. Архитектура и чистота Astro

- [ ] **Zero JS**: Компонент написан на нативном `.astro` без лишних `<script>` тегов.
- [ ] **Острова (Islands)**: Если применен UI-компонент, директива выбрана строго по матрице (`client:visible` по умолчанию для блоков ниже первого экрана, `client:load` только для Hero).
- [ ] **Типизация пропсов**: В начале frontmatter объявлен строгий `interface Props`, отсутствуют типы `any` и нетипизированные параметры.
- [ ] **Оптимизация ассетов**: Нет прямых тегов `<img>`. Все изображения используют `<Image />` или `<Picture />` из `astro:assets` с атрибутами `alt`, `width`, `height`.
- [ ] **Импорты**: Отсутствуют неиспользуемые импорты, циклические зависимости и тяжелые клиентские библиотеки.

### 2. Семантика и доступность (a11y)

- [ ] **Заголовки**: Ровно один `<h1>` на страницу (в секции первого экрана). Во всех остальных секциях соблюдается четкая иерархия `<h2> -> <h3>`.
- [ ] **Контейнеры**: Использованы семантические теги `<section>`, `<article>`, `<header>`, `<nav>`, `<footer>` вместо сплошных `<div>`.
- [ ] **Интерактивные элементы**: Кнопки реализованы через `<button type="button">`, ссылки — через `<a href="...">`. Присутствуют атрибуты `aria-label` для иконочных кнопок без текста.
- [ ] **Контрастность**: Текст и интерактивные элементы соответствуют стандарту WCAG AA по контрастности.

### 3. Стили и соответствие `DESIGN.md`

- [ ] **Токены**: Отсутствуют «магические» числа (`p-[17px]`) и произвольные цвета не из дизайн-системы.
- [ ] **Desktop-First & Mobile**: Проверена адаптивность компоновки, отсутствие горизонтального скролла на экранах `320px-480px`, тач-таргеты не менее 44x44px.
- [ ] **Reduced Motion**: Присутствует учет системных настроек отключения анимации (`prefers-reduced-motion`).

## ⚙️ Обязательный запуск валидационных скриптов

Перед финальным ответом пользователю агент **ОБЯЗАН** запустить полный пайплайн проверок в терминале через `pnpm`:

```bash
# 1. Статический анализ кода (oxlint)
pnpm run lint

# 2. Проверка форматирования (oxfmt)
pnpm run fmt:check

# 3. Валидация сборки SSG и типов (astro build / astro check)
pnpm run build
# При установленном @astrojs/check также запускается: pnpm astro check
```

> [!IMPORTANT]
>
> - Если любая из команд завершается с ошибкой (non-zero exit code):
>   1. Агент обязан локализовать и исправить ошибку в коде (например, выполнить `pnpm run lint:fix` или `pnpm run fmt`, исправить несоответствие типов).
>   2. Повторно запустить валидационный цикл до достижения **100% прохождения без ошибок и предупреждений**.
>   3. Только после этого задача считается выполненной.
> - Помните, что согласно AGENTS.md установка новых пакетов (например, `@astrojs/check`) требует согласования с пользователем. Не запускайте команды в интерактивном режиме установки сторонних зависимостей.
